# Cross-Silo-Federated-Learning-System
In the ever-evolving landscape of cybersecurity, smart grids and web applications remain prime targets for false data injection (FDI) and other web-based vulnerabilities. This project presents an efficient, privacy-enhancing vulnerability detection system that leverages cross-silo federated learning and ensemble machine learning techniques to identify and classify potential threats in SQL, XSS, and RFI attack vectors. By combining Support Vector Machine (SVM), K-Nearest Neighbors (KNN), and Naïve Bayes algorithms, the proposed system enhances prediction reliability and accuracy beyond 95%. Unlike traditional approaches that rely on rule-based detection, this machine learning-driven framework trains on historical vulnerability datasets and predicts labels such as No Vulnerability, SQL Injection, or XSS/RFI in new test data.

The system consists of several interactive modules, including user registration, login, dataset loading, NLP-based preprocessing, ensemble training, confusion matrix visualization, and real-time vulnerability prediction. The Natural Language Processing (NLP) toolkit is employed to eliminate stop words and retain only core query tokens for meaningful learning. The trained model shows high precision, recall, and F1-score, validated through a confusion matrix graph. This robust platform supports a Django web server backend and a MySQL database, enabling users to upload new test queries and identify vulnerabilities effectively. The design’s modularity and extensibility make it suitable for dynamic cyber environments and scalable security frameworks. With its interactive frontend and reliable backend prediction engine, the project contributes a practical tool for real-time software vulnerability detection and strengthens data integrity in smart applications.
